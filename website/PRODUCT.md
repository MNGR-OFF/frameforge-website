# FrameForge website

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Astro static output and TypeScript, expressly requested. GitHub Pages hosts; Namecheap manages the custom domain. The user delegated practical design decisions and asked to continue without unnecessary interviews.

## Users
Figma designers and Roblox creators who need to understand, install, and use the conversion plugins. Maintainers also need deployment and OAuth review preparation.

## Product Purpose
Design in Figma. Forge it into Roblox. Convert supported layers into real editable Roblox UI and continue editing in Studio.

## Positioning
The native hierarchy is the central promise. Unsupported graphics can become individual images without flattening the entire surrounding interface.

## Operating Context
Figma plugin selection and export; manual Roblox image asset mappings; JSON import into Studio; Play-mode testing. The website explains the process and illustrates concepts. It does not import designs or initiate OAuth.

## Capabilities and Constraints
Verified alpha package 0.1.7, native compatible layouts/text/masks, pixel/responsive/hybrid sizing, behaviors and bundled runtime. Hosted linking is not deployed. Official publicly installable listings remain unverified. The owner supplied MNGR, Morocco and contacts, and accepted monitoring/retention commitments. Final operator-identification adequacy, provider/scope review and policy adoption remain pending; the static website can publish with clearly labelled drafts. No invented proof, prices, testimonials, or credentials.

## Brand Commitments
Supplied transparent FrameForge logo; dark steel and orange ember palette specified in the brief; no purple. Discord @mngr06 is supplied creator identity. Independent from Figma and Roblox. User explicitly requested Impeccable craft and freedom from generic generated-site styling.

## Evidence on Hand
README, docs/limitations.md, docs/release-notes.md, docs/hosted-uploader.md, behavior/effect docs, and plugin/backend source. Namecheap domain registration screenshot; the latest read-only check confirms GitHub Pages DNS and valid HTTPS, with the website artifact still unpublished. No verified public OAuth connection or upload.

## Product Principles
Preserve editability, tell the truth about availability, keep existing systems intact, make conversion boundaries understandable, keep production credentials out of the static site.

## Accessibility & Inclusion
WCAG 2.2 AA target; keyboard use, visible focus, reduced motion, no-JavaScript essentials, responsive layouts, direct routes and readable long documents.
